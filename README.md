# Basqar — «На связи»

[![Проверка кода и сборки](https://github.com/rustamprogrammer/basqar-support-copilot/actions/workflows/ci.yml/badge.svg)](https://github.com/rustamprogrammer/basqar-support-copilot/actions/workflows/ci.yml)

Помощник администратора **Grand Mobile**: разбирает обращения игроков, определяет категорию и срочность, находит фрагменты правил и готовит ответ для проверки человеком. Игрок отправляет сообщение; администратор получает очередь с причинами решения, источниками и редактируемым черновиком.

Конкурсный интерфейс: **`POST /triage`**, 14 категорий, приоритеты **p0–p3**, языки **RU / KK / UZ / EN / ES / PT**. Веб-интерфейс сохраняет разделы «Вопрос», «Помощь», «Нарушение», «Корзина», «Не определено»: это маршруты поддержки, отдельные от конкурсной категории.

Эта рабочая копия содержит обновления и инструкции для локальной проверки. [Исходный репозиторий команды](https://github.com/BAITC-Hacks/hack-b6eba4f7-basqar) архивирован; история проекта сохранена в fork.

## Жюри: открыть сайт

**[Открыть веб-версию BayPos → https://baypos.kz](https://baypos.kz)**

Адрес веб-версии команды — **[baypos.kz](https://baypos.kz)**. Для просмотра в браузере не требуется скачивать репозиторий и устанавливать зависимости. Если открывается форма входа, используйте данные доступа, переданные командой отдельно. Сценарии проверки приведены в разделе [«Что попробовать»](#что-попробовать).

Доступность ИИ зависит от подключения и лимитов опубликованного сервера; фактическое участие модели проверяйте в результате обработки обращения. Если веб-версия временно недоступна или нужна воспроизводимая проверка на своей машине, используйте локальный запуск ниже.

## Жюри: запустить локально

Нужны **Node.js 24.x**, npm, Git и приватный **`rules.json`** из конкурсной выдачи. Для работы ИИ также нужен API-ключ, переданный командой отдельно, либо собственный разрешённый ключ. **Ключа команды и приватных правил в GitHub нет.** Без ключа работают локальные алгоритмы, интерфейс и тесты; ИИ включается отдельным действием.

### 1. Скачать и подготовить

```powershell
git clone https://github.com/rustamprogrammer/basqar-support-copilot.git
cd basqar-support-copilot
npm run setup:local -- --rules "C:/private/handout/rules.json"
```

Замените путь на свой `rules.json`. Команда устанавливает зависимости, готовит приватный корпус, собирает сайт и создаёт таблицы в пустой базе. Готовая база сохраняется; при частично обновлённой базе команда остановится с инструкцией. Подробности — в [руководстве](docs/jury-guide.md#локальный-запуск).

Если выдача находится в архиве, вместо `--rules` используйте `--archive "C:/private/handout.tgz"` (нужен `tar`).

### 2. Запустить сайт

```powershell
npm start -- --port 8787
```

Откройте **[http://127.0.0.1:8787](http://127.0.0.1:8787)**. Оставьте терминал работающим; остановка — Ctrl+C. База сохраняется между запусками. В открытом деморежиме «Обращения» доступны без пароля.

### 3. Подключить ИИ — отдельно от установки

Поместите переданный приватно ключ в локальный `.dev.vars` по [.dev.vars.example](.dev.vars.example). Не публикуйте этот файл. При работающем сайте во **втором терминале** из корня проекта:

```powershell
npm run ai:configure
```

Команда читает `.dev.vars`, настраивает `gpt-6-luna` и режим сложных обращений через локальный сервер. **Платного проверочного вызова нет.** Уже сохранённый ключ остаётся прежним; явная замена — `npm run ai:configure -- --replace-key`. Подробности и лимиты: [ключ команды и расходы](docs/jury-guide.md#ключ-команды-и-расходы).

Проверьте **[http://127.0.0.1:8787/api/health](http://127.0.0.1:8787/api/health)**: `ok: true`, а после подключения ИИ — `processingMode: "rules+ai"`, `aiReviewEnabled: true`. Поля `aiUsed` / `aiLimit` показывают счётчик, `build` — сведения о запущенной сборке. Это состояние конфигурации; фактический режим конкретного обращения виден в его результате.

## Что попробовать

1. В **«Проверке сообщения»** отправьте `Что такое ДМ?`: проверьте опубликованную справку и возможность попросить администратора.
2. Затем отправьте `У меня украли аккаунт, почту восстановления заменили, войти не могу`. В **«Обращениях»** проверьте категорию, приоритет, срочность и черновик. Это сценарий проверки, а не гарантия безошибочного ответа.
3. В **«Логике обработки»** сравните локальное решение, участие ИИ и найденные источники с текстом обращения.
4. Отредактируйте черновик и отправьте ответ как администратор. Сгенерированный ИИ текст требует ручной отправки; только ограниченные опубликованные FAQ могут отвечать автоматически.
5. Проверьте собственное вымышленное обращение на одном из шести языков. В **«Тестах и статистике»** можно отдельно прогнать строки локальным алгоритмом без API; этот режим не измеряет качество ИИ.

Используйте синтетические обращения: деморежим открывает общую очередь, ответы и базу знаний посетителям этой установки. При недоступном ИИ или исчерпанном лимите остаются алгоритмы и проверка оператором.

## Как устроено решение

```text
Обращение игрока → нормализация и локальный алгоритм → безопасный опубликованный FAQ
                                                   ↘ ИИ + фрагменты правил
                                                     → проверка формата и источников
                                                     → черновик для администратора
```

ИИ получает исходный текст игрока и до четырёх фрагментов правил, выбранных независимо от локальной категории. Ответ проверяется по схеме и существующим ID источников. При ошибке API сохраняется локальное решение для оператора. Проверка формата не гарантирует смысловую корректность текста или цитаты.

| Интерфейс | Назначение |
| --- | --- |
| `GET /api/health` | Состояние базы, режим, счётчик ИИ и версия сборки. |
| `POST /triage` | JSON: язык, категория, приоритет, извлечённые поля, черновик, источники, `needs_human`. |
| `POST /api/messages` | Путь веб-интерфейса: сохранение обращения, результата и очереди. |
| `make predict IN=tickets.jsonl OUT=pred.jsonl` | Пакетный локальный триаж, без API. |

В Windows без Make: `npm run triage:predict -- --in tickets.jsonl --out pred.jsonl`. [Пример HTTP-запроса](docs/jury-guide.md#проверка-состояния-и-api), [точный контракт и категории](docs/triage.md).

Стек: React, TypeScript, Vinext/Vite, Drizzle ORM, Cloudflare D1 (локально SQLite), Wrangler. Отдельный сервер БД и аккаунт Cloudflare для локального запуска не требуются.

## Результаты: изученные 100 и новые 20

Проверка от **31 октября 2026 года**. «Все поля» — одновременно верные категория, приоритет и язык с сохранением обязательной проверки человеком. Сбои модели входят в знаменатель.

| Набор и режим | Категория | Приоритет | Язык | Все поля | Критические p0 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 100 сложных примеров: алгоритмы | 47/100 | 59/100 | 86/100 | 38/100 | 6/19 |
| Те же 100: только ИИ до исправлений | 82/100 | 87/100 | 91/100 | 78/100 | 15/19 |
| Те же 100: связка после исправлений | 98/100 | 100/100 | 99/100 | **97/100** | 19/19 |
| Дополнительные 20: алгоритмы | 11/20 | 13/20 | 20/20 | 9/20 | 3/6 |
| Дополнительные 20: связка после фиксации версии | 18/20 | 18/20 | 20/20 | **17/20** | **4/6** |

**100 примеров использовались для исправлений; 97/100 — результат на изученном наборе.** Дополнительные 20 обработаны один раз после фиксации версии, без последующей подгонки классификатора. Оба набора синтетические, с предварительными авторскими метками, без проверки носителями языков. Это не оценка точности на реальных обращениях и не обещание конкурсного балла.

На новых 20 примерах два критических случая получили недостаточный приоритет. В черновиках также найдены ошибки языка, смысла и применимости цитат. Ручная проверка обязательна; она сама по себе не исправляет порядок очереди. Фиксированные наборы, расходы и оставшиеся ошибки — в **[отчёте о 100 + 20 обращениях](docs/adversarial-verification-2026-10-31.md)**.

Проверка поставки для жюри: **1469/1469 тестов**, TypeScript, ESLint и production-сборка прошли. Публичный CI использует явно синтетический минимальный корпус: проверяет код и сборку, но не качество поиска по настоящим правилам. Для полноценной демонстрации и оценки нужен приватный корпус. Установка с настоящим конкурсным архивом, создание базы и импорт ключа дополнительно проверены локально без платных API-запросов.

## Расходы и ограничения

Конкурсный RAG настроен на `gpt-6-luna`. На финальном изученном наборе 100 обращений потребовалось **99 API-вызовов**, известная токенная стоимость — **$0.024653325**; на дополнительных 20 — **$0.005098625**. Это измерения конкретных прогонов по настроенным тарифам, не фиксированная цена будущего списания. Последовательный p95 составил 2,54 с и 2,76 с соответственно; публичный туннель и нагрузка так не измерялись.

Рабочий сервер ограничен **100 платными попытками на установку**, включая ошибки и ручную проверку ключа; счётчик переживает перезапуск и замену ключа. Есть кэш, ограничения частоты и проверка верхней оценки стоимости запроса $0.002. Лимит попыток не заменяет долларовый лимит провайдера. `npm test`, публичный CI, пакетная страница статистики и `make predict` не вызывают платный API.

Изображения не анализируются: учитывается наличие вложений. Уверенность алгоритма — эвристика. Изменение разметки или базы знаний не обучает веса модели; fine-tuning API-модели не выполнялся. Система готовит решения для администратора и не назначает наказания, возвраты или разблокировки.
